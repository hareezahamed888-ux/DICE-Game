# Dice Game

A simple, fun browser-based dice rolling game.

## Features

- Roll virtual dice with smooth visual feedback
- Clean, modern UI with custom dice face images
- Pure client-side — no server required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## How to Play

1. Open `index.html` in any modern browser
2. Click the roll button
3. Watch the dice result update instantly

```bash
npx serve .
```
